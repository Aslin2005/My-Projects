# Optical Lock-In Amplifier PCB

## Overview

Designed a four-layer mixed-signal PCB for an STM32H743-based optical lock-in amplifier.

## Features

- INA826 instrumentation amplifier
- Low-noise analog front-end
- Controlled impedance routing
- Gerber generation
